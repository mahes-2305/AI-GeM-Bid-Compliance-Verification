# SIH Presentation Builder

When requested to generate presentation or PPT content for an SIH project, ALWAYS use the following strict structure:

1. **Title Slide:** Project Name, Problem Statement ID, Team Name, and a strong Tagline.
2. **The Problem:** 3-4 bullet points outlining the core issues the PS addresses.
3. **The Solution:** How the project directly solves the problem. 
4. **Key Features & USPs (Unique Selling Propositions):** Highlighting the unique parts of the project (e.g., AI integration, security, UX).
5. **Technical Architecture & Tech Stack:** Frontend, Backend, Database, AI engines, and Data Flow.
6. **The Workflow (Live Demo Guide):** Step-by-step user journey.
7. **Scalability & Future Scope:** How the project can be scaled to national or enterprise levels.
8. **Speaker Notes:** Always include a dedicated section at the bottom with 2-3 strategic tips on how to pitch the solution to judges (emphasizing time saved, data privacy, and architecture).

**Instructions:**
- Keep bullet points concise (ready for slides).
- Read the project codebase to automatically infer the Tech Stack and Features if not provided.
- Ensure the tone is professional, technical, and persuasive.
